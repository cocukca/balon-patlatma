# Balon Patlatma Oyunu

Küçük, statik HTML/CSS/JavaScript balon patlatma oyunu. Balonların içindeki hayvanları patlatır, skor toplar ve ses açıkken Türkçe hayvan adlarını dinleyebilirsin.
